# minictf
My project to make a small ctf platform


Demo link:

https://minictf-zeta.vercel.app/


How to use: 

open command line or terminal
git clone https://github.com/arsenal4eva/minictf

python run.py

then visit 127.0.0.1:5000 for the ctf platform
includes user registration, challenge creation, flag verification, admin panel, scoreboard, teams, point decay.


If hosting CTF:
allow port 5000, let others access through ip:5000
